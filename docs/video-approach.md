# 動画対応の方針（顔固定・まばたき動画）

設計書 v2 §20–24 / §36 Phase 4–6 に対応する検討メモ。
対象は「顔をほぼ動かさず、まばたきのみする動画」という具体的なユースケース。

## 検討した案: 毎フレーム差分

> まばたき前の動画 + リファレンス静止画 → 毎フレーム差分を取って抽出

**推奨しない。** 理由:

1. **まばたき中は未装着リファレンスと目の開き具合が一致しない。**
   差分の大部分が「まぶたの動き」になり、まつ毛の証拠として使えない。
2. **フレーム独立処理はちらつく。** 同じ毛先の Alpha がフレーム間で 0.7 → 0.3 → 0.8 と揺れる
   （設計書 §24 の Temporal Consistency 問題）。
3. **コストが高い。** matting は 1 ROI あたり約 1 秒。全フレームに対して回すのは無駄が大きい。

## 推奨: 「抽出は 1 回、追従はランドマーク warp」

```text
動画
 ├→ ベストフレーム選択（目が最も開いている、ブレが少ない）
 │     └→ 既存パイプラインで 1 回だけ抽出 → product_rgba（基準まつ毛レイヤー）
 └→ 全フレーム
       ├→ MediaPipe でまぶたランドマーク追跡
       ├→ 開き具合に応じて基準レイヤーを warp（根元を軸に回転 + 縦圧縮）
       └→ Alpha 合成
```

要点:

- **抽出は 1 回だけ**なので、フレーム間でまつ毛の形状・毛束・本数が完全に一致する
  （= Level 3 Pixel Preserve が動画でも保たれる）。ちらつきが原理的に発生しない。
- まばたきは**まぶたの開閉に伴うまつ毛の回転・短縮**として近似する。
  根元位置はまぶたのランドマークに追従させ、毛先は開度 `t = eye_open / eye_open_best` に応じて
  根元を中心に回転・縦方向へ圧縮する。
- **毎フレーム差分は抽出ではなく検証・信頼度に使う。**
  warp 結果と実フレームの差が大きいフレームはオクルージョン・大きな動きとして検出し、
  そのフレームだけ別処理へ回す。

### ベストフレーム選択の指標（設計書 §21）

`sharpness`（Laplacian 分散）、`eye_open`（まぶた間距離 / 目幅）、`face_angle`、`exposure`。
まつ毛抽出用途では **eye_open が最大** かつ **sharpness が上位** のフレームを選ぶ。

## 前処理としてのスタビライズ

手ブレ低減は有効だが、**汎用の映像スタビライザーより顔ランドマーク基準の安定化が適している。**

| 方式 | 基準 | 評価 |
|---|---|---|
| 顔ランドマーク基準 affine（推奨） | 顔 | 全フレームをベストフレームの顔位置へ揃える。手ブレ除去とまつ毛レイヤーの位置合わせが同一変換で済み、顔が完全に固定される。MediaPipe で実装可能。出力時に逆変換をかければ元のカメラの動きも復元できる |
| 汎用スタビライザー（`ffmpeg vidstab` 等） | 背景 | 背景基準で揃えるため顔の動きは残る。補助的な事前処理としてなら有用 |

```python
m, _ = cv2.estimateAffinePartial2D(lms_frame[ALIGN_POINTS], lms_best[ALIGN_POINTS], method=cv2.LMEDS)
stabilized = cv2.warpAffine(frame, m, (w, h))   # 顔を基準フレームへ固定
# ... 合成 ...
out = cv2.warpAffine(composited, invert_affine(m), (w, h))  # 元のカメラの動きへ戻す
```

既存の `pipeline.align_b_to_a` と同じ考え方なので、実装は流用できる。

## 不自然になる場合のフォールバック

閉じかけフレームで warp 近似が破綻する（毛が折れる・伸びる）場合は、その区間のみ
video matting へ切り替える 2 段構えとする。

- Promptable Video Segmentation + Tracking（SAM2 系）
- Temporal Matting（MatAnyone 系）

最初からこちらを採用しないのは、計算コストが高く、かつフレームごとに Alpha を推定するため
形状の同一性保証が弱まるため。

## 開発順序

1. フレーム分解 + ベストフレーム選択（既存パイプラインへの入力を作るだけ）
2. 顔ランドマーク基準スタビライズ
3. まぶた追従 warp + 全フレーム合成 → 動画書き出し
4. 差分による破綻フレーム検出
5. （必要なら）破綻区間のみ video matting
