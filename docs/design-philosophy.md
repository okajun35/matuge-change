# 設計思想: なぜ商品を生成AIに任せないのか

この文書は、`matuge-change` の中心方針である **Generative Product Preserve**
（商品を生成AIの処理対象から外す）の理由と、その適用範囲・限界をまとめる。

## 1. 「変更しないで」は保証にならない

生成AIに「商品は変更しないで」と指示することはできるが、出力された商品が元画像と同一である
ことを保証することはできない。

実際に、人物をAIモデルへ変更すると目元も再生成され、装着していたつけまつ毛が次のように
変化する。

- まつ毛の長さが変わる
- 毛束の本数や密度が変わる
- カールの強さが変わる
- 毛先の方向が変わる
- 目尻側のボリュームが変わる
- 元の商品には存在しない毛が生成される

![生成AIに人物を変更させると、まつ毛（商品）まで変わってしまう](../images/problem-generative-ai-changes-product.png)

EC の商品画像では、「似た商品」ではなく、**実際に販売する商品の形状・毛束・長さ・カール・
装着状態を維持すること**が重要である。掲載画像と届いた商品が違えば、返品・クレーム・低評価
レビュー・ショップ評価の低下につながる。

## 2. 採用した設計

そこで本プロジェクトでは、

> **「生成AIに商品を正しく描かせる」のではなく、
> 「商品を生成AIの処理対象から外す」**

という設計を採用している。

商品領域は元画像・元動画から抽出または保持し、生成AIには人物側の加工を担当させ、最後に
商品を画像処理で再合成する。

```text
元画像 / 元動画
   │
   ├─ 商品領域 ──────────────┐
   │      抽出・保持          │
   │                         │
   └─ 人物領域               │
          ↓                  │
       生成AIで加工           │
          ↓                  │
          └──────────────→ 再合成
```

この設計では、生成AIの自由度と、商品の同一性・再現性をできるだけ分離する。

## 3. 商品領域に許す操作

商品領域に許すのは **相似変換（移動・縦横比固定の拡縮・回転・反転）と Alpha 合成だけ**である。

- 自由変形・パースペクティブ変換・非相似 warp は行わない
  （毛足の長さや毛束の間隔、カールの縦横比が変わってしまう）
- 生成AIによる商品の描き直し・inpaint は行わない
- 動画モードでは商品を含む目元領域に幾何変換を掛けず、元フレームのピクセルをそのまま貼り戻す

却下した方式とその理由は [handover.md](handover.md) §3 と
[video-algorithm.md](video-algorithm.md) §15 に記録している。

## 4. 「AIを使っていない」ではない

本システムは「AIを使わない画像処理」ではない。顔・目元の位置推定には MediaPipe Face
Landmarker の機械学習モデルを利用する。一方で、**商品まつ毛そのものを生成AIに再生成させる
ことは避ける**、というのが設計上の中心方針である。

## 5. 「ピクセル完全一致」でもない

保持の目標は「生成AIに商品を再生成させず、実物画像由来の商品外観を可能な限り保持して
再利用する」ことであり、最終出力が元画像とビット単位で一致することではない。

- 静止画は Matting の Foreground 推定と、相似変換の補間リサンプルを通る
- 静止画は ROI 幅 1100px を超える場合に縮小して処理する
- 動画は目元コア領域を無変形で使うが、境界の feather で AI 画像と混色する
- 動画は H.264 / `yuv420p` の再エンコード（量子化・クロマサブサンプリング）を通る

モードごとの保持強度の定義は [../README.md](../README.md) 「商品保持の考え方」を参照。
